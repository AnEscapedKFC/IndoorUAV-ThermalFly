## 观察与验收

- 笔记本任务沿用抵近打开的电脑、保持可见、从上方向下观察屏幕并悬停的指令。屏幕正反面由两张独立标定照片的屏幕四角三角化确定，角点最大重投影误差为 2.13 px（320 × 240）。使用每个实际相机位姿验证屏幕中心在视野内，每次决策验证 RGB 检出；悬停还要在屏幕正面上方且光轴朝下。这里验证的是屏幕的观察姿态。
- 沙发降高任务沿用从会议桌一侧接近、降低观察高度并悬停的指令。验收要求末态相对起点至少降低 0.10 m。两类普通抵近任务在严格档都要求悬停期参考点在画面中央 40% × 40%，且 STOP 帧和其后每 0.5 秒的 4 张 RGB 检测框中心均在该区域。
- 沙发扫视任务明确要求从会议桌一侧接近，在近处由左到右观察其正面，最后面朝沙发悬停两秒。接入层以机体偏航扫视，保持云台俯仰固定。这项任务用历史 RGB 合成后的正面覆盖代替末帧完整目标框居中，末态仍需能看见沙发。
- 严格档要求两秒悬停全程在 0.4–0.8 m，大致档要求全程在 0.5–1.5 m。两个档都要求完成指令动作、无碰撞无越界、悬停漂移 ≤0.12 m，且最后 0.5 秒速度均 ≤0.10 m/s。普通抵近任务的大致档放宽了居中要求。扫视任务两档均须通过历史图像验收。

## 沙发历史 RGB 如何组成全貌

在独立的原始会议室标定照片上勾画可见的靠背、座面、左右扶手、前面板和右侧面，扣除茶几、衣物和椅子的遮挡。“全貌”限于这张正面参考照片可见的沙发表面，覆盖率按该参考图的像素面积统计。[参考照片及轮廓](sofa_reference.png)

离线逐帧解码 20 Hz 实际飞行 RGB，根据逐帧相机位姿、内参和 RGB 3DGS 深度将观察到的纹理重投影到参考图。用深度一致性（0.08 m 加光轴深度的 3%）、颜色差（RGB 各通道绝对差的平均值 ≤50/255）和图像边界过滤遮挡或无法确认的像素。深度来自原轨迹的相机位姿，另在每个决策时刻与飞行中留存的深度图核对。按视线集中位置在参考图上的横坐标验证左右顺序；相邻有效帧有共同可见区（至少覆盖较小区域的 12%），时间缺口不超过 0.15 s。只用距沙发参考点 ≤1.5 m 的图像验收；整段视频的覆盖另存为诊断。

本轮将通过线设为总覆盖 ≥90%、每个标注部件和左中右各区域覆盖均 ≥70%，并按左、中、右顺序观察。西侧扫视有 136 张连续帧可拼接，从 14.30 s 至 21.05 s，扫视段中最佳单帧覆盖 47.7%，合成后为 80.3%。左扶手 100.0%、靠背 96.4%、座面 80.9%、右扶手 82.6%；前面板 0.0%、右侧面 9.9%，右三分之一区域合计 60.7%。同一段逆序播放、重复单帧都未通过顺序检查。拼图中浅灰色为标注内未证实的区域，深灰为标注外区域。该指标依赖场景几何和独立标注，尚未对更多房间和标注者验证。[按序的原始 RGB 帧](scan_2/ordered_rgb_views.jpg) · [近距历史拼图](scan_2/close_sweep_mosaic.png) · [逐帧证据](scan_2/coverage_frames.json)

## 专家数据与复跑

准备阶段仅从指定记录提取指令及对应类别、首帧位置、姿态、速度和固定云台俯仰。扫视指令在沙发任务描述基础上明确了从左到右的方向。在线飞行和离线验收均通过独立入口阻断对专家记录目录的文件读取。运行时的相机画面来自本次动力学飞行；定位使用冻结的 RGB 检测器、通用宽度先验、相机标定及当前里程计，IndoorUAV-Agent 的航点提议参与接近速度选择，停止与扫视由接入层控制。沙发轮廓、参考点、纹理拼图和覆盖分数仅进入离线验收。本轮没有训练、拟合专家航点或回放专家动作。发布权重 32 个参数文件逐一对照通过，模拟器受版本控制文件干净。[允许字段清单](../../furniture_tasks.json) · [权重和隔离校验](isolation_audit.json)

在 grounding_study 目录运行，可复用既有模型推理服务。任务运行器会复用已完成的同名飞行；本报告目录包含以上六次原始飞行的完整输出。

```bash
./launch.sh run.py flight furniture --prepare
python -B ../bridge_client.py --socket ../runtime/grounding-study.sock serve -- ../scripts/model_worker.sh
```

另一个终端在同一目录执行飞行和独立评分。

```bash
./launch.sh run.py flight furniture
./launch.sh metric_flight/furniture_score.py
```

# 动力学飞行中的 13.5 米航程和可见物体观察

开启自动检查后，走廊按无碰撞计 4/5，按无碰撞且达到 13.5±0.4 米计 4/5。关闭时两项分别为 4/5 和 0/5。会议室仅提示到优化版的严格成功数为 0 → 3（各 6 条），STOP 前连续一秒目标居中为 0 → 6。

检查器设为自动时，数值必须与飞行高度或飞行距离明确关联，两者任一即可触发。只有高度时只修正高度；只有距离时执行相对位移与里程控制，不引入旧高度设定。关闭开关时仍计算里程、记录碰撞并按相同规则评分。会议室三类指令均没有数值高度或航程，检查器全程自动关闭。视觉观察策略有独立开关。

## 走廊

所有比较组使用同一句英文 Fly forward 13.5 meters.。每 0.05 秒根据真实机体位置变化累计三维路径长度，两组也都获得累计值、剩余值及沿起始机头的有符号净位移。碰撞判定优先，首次达到 13.5 米即完成飞行。主指标分别是全程无碰撞、无碰撞且实际航程误差 ≤0.4 米。初始机头净进度及沿该方向直行 13.5 米的平面终点误差另外列出。走廊不要求悬停、特定终点偏航或旧专家终点。已知空域越界单独记录。

|---|---|---|---|---|
| 原爬升起点 | 12.045／否 | 13.511／否 | 13.365 | 0.14 |
| 原定高返航起点 | 9.027／否 | 13.507／否 | 13.354 | 0.19 |

自动组根据剩余距离约束模型航点，持续推进直至在线里程到达；从当前 RGB 线段的消失方向估计走廊轴，保留起始前向半平面。关组让模型独立提出航点和提前停止。开启后的成功属于冻结模型与外部里程控制的组合。初版仅沿初始航向闭环，两条小偏航路线发生碰撞；正式版在这两条均达到航程。反向起点从 x=31.55 米向东出发，在 x≈37.25 米处发生碰撞，此时路径约 5.81 米，场景标定的东侧 x 上界为 38 米。

## 会议室

六个起点的初始空调均可见，固定云台，种子 42。新的两个弧线起点相对原机身分别前移/后移 0.16 米、侧移 0.12 米、改变偏航 ±8°。四个已有提示组使用相同的真实飞行记录重算，两处新增起点的提示组和全部六条优化组实际飞行。接近时用检测框、相机内外参和里程估计目标方向与距离，以 0.80 米的通用空调宽度初始化尺度，获得足够视差后通过多帧视线修正。弧线阶段增加沿目标切线的移动，用目标水平边缘估计正面朝向，选择互补视角；检测短暂失配时用前后向一致的当前帧光流继续确认。达到观察角度并连续居中后减速，执行 2 秒悬停。优化组以 0.5 秒间隔做视觉修正；提示基线沿用 1 秒策略决策。本对照测量整套观察执行器的效果，包括控制周期与减速方式。

## 复跑

在 indooruav_rgb_bridge 启动已有的 29999 模型服务，进入 grounding_study 执行以下入口。原始模型候选、最终下发航点、在线里程、物体方位、阶段和逐帧飞行状态保存在各回合目录。

```bash
# 在接入层根目录，用独立终端启动
python -B bridge_client.py --socket runtime/grounding-study.sock serve -- scripts/model_worker.sh
# 在 grounding_study 目录
./launch.sh run.py flight corridor --waypoint-speed legacy --corridor-distance 13.5 --waypoint-check off
./launch.sh run.py flight corridor --waypoint-speed legacy --corridor-distance 13.5 --waypoint-check auto
./launch.sh run.py flight room --waypoint-speed legacy --room-goal reference --room-policy hint --cases holdout_room_obj_ac_east_to_west holdout_room_obj_ac_west_to_east
./launch.sh run.py flight room --waypoint-speed legacy --room-goal reference --room-policy visual
./launch.sh metric_flight/evaluate.py
./launch.sh metric_flight/check.py
```
